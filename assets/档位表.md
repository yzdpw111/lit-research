# 档位表（模板）

> **怎么用**：`lit ingest` 会**自动**在 `02_候选库/refs.json` 里写 `tier`（**只往下判**）。
> 本表是**人读版**，用来复核自动判定、以及记录**人工改判**。
> ⚠️ 人工改过的条目，在 `refs.json` 里必须写 `tier_source: "manual"`——**重跑 ingest 不会被覆盖**。

## 六个档位（S-01，白名单在 lit.config.json）

| 档位 | 允许做什么 | 不许做什么 |
|---|---|---|
| `full_text` | **支撑具体论断**（数字带页码/表号） | 抽不出文字的不算 |
| `abstract_only` | 进著录、进泛述 | **不许支撑论断；不许进 04_精读/** |
| `unreadable` | 如实标注"需人工读" | 不许当读过 |
| `source_conflict` | **并列**记两个值 | 不许单方取舍 |
| `insufficient_evidence` | **该停就停** | 不许凑一张图/编一个数 |
| `bad_source` | 标注 + 给对策 | 不许悄悄丢文献 |

## 常见改判情形

| 情形 | 改成 |
|---|---|
| 扫描件 PDF，抽不出文字 | `unreadable` |
| 摘要与正文数字对不上 | `source_conflict`（**两个值都记**） |
| 计划要画 PR 曲线，但原文没有可复现数据 | `insufficient_evidence`（**放弃那张图**） |
| 数据源不返回刊名，导致 GB/T 7714 缺字段 | `bad_source` |
